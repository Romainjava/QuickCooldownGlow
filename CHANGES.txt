    fix(spec): use C_SpecializationInfo for spec lookup (Forever client)
    
    - Global GetSpecialization / GetSpecializationInfo are deprecated since 11.2.0
      and absent on the Forever (Camelot, Interface 16001) client, so the hot path
      Evaluate -> GetCurrentSpecID crashed with "attempt to call a nil value"
    - Add CG.GetSpecInfo compat layer: C_SpecializationInfo.GetSpecialization /
      GetSpecializationInfo first, legacy globals as fallback, 0 (generic slot)
      when neither is available; never raises
    - Options: resolve the spec name through CG.GetSpecInfo as well
